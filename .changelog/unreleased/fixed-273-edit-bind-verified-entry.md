- **`edit` and `replace_lines` bind the read and the write to the workspace entry they checked (bob#273).** A relative path resolves against the session's workspace root and a path that resolves outside it — absolute, through `..` or through a symlink — is refused before either tool reads file content or writes. Bob's `edit` disables pi's diff preview, which would otherwise read by path. Bob opens the checked target with `O_NOFOLLOW` and reads and writes through the descriptor only while its device and inode are the checked entry's; `edit`'s write also requires the identity its read saw. The checked canonical path's final component swapped for a symlink or for another file between the check and the open is refused, before any write. Both tools finish partial writes and refuse zero write progress. An intermediate directory swapped for a symlink between the check and the open is not detected when the new path still leads to the same device and inode (Node exposes no openat). This is an in-process guard against model mistakes; a hostile local process is the OS boundary's job (bob#189). (`test/shell/edit-bind-verified-entry.test.ts`, `test/shell/bob-edit-tools.test.ts`)
