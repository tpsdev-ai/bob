- **README usage section matches the CLI.** The usage section no longer advertises what the CLI does not support: `bob serve` (there is no `serve` command — a run with no prompt *is* the persistent mode), an interactive `bob run` mode (`bob run` parses `--interactive` but refuses it when it is on), and "system cron" (scheduling is the persistent `bob run` runtime firing bob.yaml `cron:` entries in-process, not an OS cron). A `test/readme-commands.test.ts` now reads the `bob <command>` names the README carries in its code spans, its code fences and the Commands table and fails if the CLI rejects any of them, and fails if a README code span or code fence spells `--interactive` as a word, since the interactive `bob run` mode is unsupported; it also requires the names it extracts to include at least `run`, `launch`, `init` and `onboard`, so an empty extraction cannot pass.
