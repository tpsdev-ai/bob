- **README usage section matches the CLI.** The usage section no longer names commands or flags the CLI does not have: `bob serve` (there is no `serve` command — a run with no prompt *is* the persistent mode), `--interactive` (the CLI rejects it), and "system cron" (scheduling is the persistent `bob run` runtime firing bob.yaml `cron:` entries in-process, not an OS cron). A `test/readme-commands.test.ts` now reads the `bob <command>` names the README carries in its code spans, its code fences and the Commands table and fails if the CLI rejects any of them, and fails if the retired `--interactive` flag appears as a word in a code span or code fence; it also requires the names it extracts to include at least `run`, `launch`, `init` and `onboard`, so an empty extraction cannot pass.
