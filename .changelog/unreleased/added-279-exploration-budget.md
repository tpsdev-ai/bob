- **Exploration budget for one-shot runs (#279, #281).** With budget N, `runAgent` attempts an instruction after N tool calls since the last credited edit and stops at 2N with `exploration_budget_exhausted`. A reset requires a file-edit result with `isError: false`, no refusal, and tool-specific success evidence. `builder-local` sets N to 20, overridden by `run.exploration_budget` in bob.yaml. `bob doctor` shows the newest log's outcome and exit code when found within its bounded tail scan.
