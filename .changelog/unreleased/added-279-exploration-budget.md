- **Exploration budget for one-shot runs (#279, #281).** With budget N, `runAgent` instructs after N non-progress calls and stops at 2N with `exploration_budget_exhausted`. Non-edit calls count at start; edit calls count at end unless `isError` is explicitly false. Only file-edit tools with an own `writer` classification reset the count; command runners do not. `builder-local` sets N to 20, overridden by `run.exploration_budget` in bob.yaml. `bob doctor` shows the newest log's outcome and exit code when found within its bounded tail scan.
