- **The systemd `ExecStart` line now double-quotes every argument (an allowed form per `systemd.syntax`), with backslash-escaped `\` and `"` inside values (bob#222).** Arguments whose paths contain spaces or quotes are wrapped in double-quotes; embedded `\` or `"` is prefixed with `\`. The renderer refuses CR/LF/NUL in any ExecStart arg. Each `%` and `$` in arguments is doubled (`%` → `%%`, `$` → `$$`) so systemd passes them through literally.
