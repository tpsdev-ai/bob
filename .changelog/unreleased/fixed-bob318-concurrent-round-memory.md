- **Per-PR round memory writes each round as its own record (#318).** Recall lists up to 3 records ordered by client-supplied `createdAt`, then id, descending; ties need not follow write order. Validated rows supply recall, with remaining slots filled from the earlier single record. After a successful write, pruning lists up to 8 records after the first 3 and deletes only validated rows with parseable `createdAt` at or before this write's `createdAt` minus a 10-minute protection window, excluding the written id. Retention can exceed 3 until rows age past the window and a later write prunes them. Failed cleanup is logged and the write still returns `written`. (`src/shell/pr-memory.ts`, `test/shell/pr-memory*.test.ts`)
