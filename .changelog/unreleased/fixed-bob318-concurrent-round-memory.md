- **Per-PR round memory writes each round as its own record (#318).** Two rounds of one PR that end at the same time write two records (subject: the PR key; createdAt: the writer's clock at the write). Recall lists the PR's first 3 records in Flair's `createdAt` order (ties by id), shows those that validate, and fills any remaining slots from the single record the previous writer kept under the PR key. After each write, bob lists up to 8 records after the first 3 and requests a delete of each one that validates as this PR's round record; a failed listing or delete is logged and the write still reports success.
