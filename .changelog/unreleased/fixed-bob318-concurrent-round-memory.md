- **Per-PR round memory writes each round as its own record (#318).** Two rounds of one PR that end at the same time write two records (subject: the PR key; createdAt: the writer's clock at the write). Recall lists up to 3 of the PR's records, latest writes first (`createdAt` descending, ties by id descending), shows those that validate, and fills remaining slots from the single record the previous writer kept under the PR key. After a successful write, bob lists up to 8 records after the first 3 in that order and deletes validated round records except the id just written; a failed listing or delete is logged and the write still reports success. Round-end request timeout budgets total up to 20 s (2 s each for the write, listing and up to 8 sequential deletes). (`src/shell/pr-memory.ts`, `test/shell/pr-memory*.test.ts`)
