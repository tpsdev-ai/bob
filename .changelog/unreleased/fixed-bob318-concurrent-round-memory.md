- **Per-PR round memory writes each round as its own record (#318).** Two rounds of one PR that end at the same time write two records (subject: the PR key; createdAt: the writer's clock at the write). Recall lists up to 3 of the PR's records, latest `createdAt` first (ties by id), shows those that validate, and fills remaining slots from the single record the previous writer kept under the PR key. After a successful write, bob lists up to 8 records after the first 3 in that order and requests a delete of each one that validates as this PR's round record; a failed listing or delete is logged and the write still reports success. (`src/shell/pr-memory.ts`, `test/shell/pr-memory*.test.ts`)
