- **`bob init --force` cleans up a temp file a killed run leaves behind, when that temp's owner has exited (#334).** A publish writes a sibling temp before renaming it into place, so a run killed in that window leaves `.<file>-bob-init-<pid>-<start>-<uuid>.tmp` behind. The next `--force` run removes a temp whose owner marker names a process that is gone, and keeps one whose owner still runs; it does not follow a symlinked directory at or below the agent root, and removes only names that carry the init token. Cleanup runs on the `--force` path, the rerun that reaches publication. (`src/shell/init.ts`, `test/shell/init-force-temp-cleanup-334.test.ts`)
