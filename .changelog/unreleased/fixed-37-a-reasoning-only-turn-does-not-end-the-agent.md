- **A reasoning-only turn no longer ends the agent mid-task (#256).** A turn whose last assistant message carries no text, no tool call, and actual reasoning/thinking content is not a final answer, but pi treats a turn with no tool call as the agent being finished, so the run ended with the work unfinished. bob now re-prompts the SAME session with `Continue: take the next action, or give your final report.`, up to three re-prompts, and stops if the fourth ending is still reasoning-only; one budget covers the whole run, the compaction retry included, and it is a constant, so a model that answers with reasoning only cannot hold the run. A run still reasoning-only after the bound ends with the honest outcome `reasoning_only` — never a normal completion — and the outcome record carries no model reasoning. Applies to every path that drives an agent run: the one-shot `bob run`, mail turns, `bob launch --prompt`, and every admitted runtime turn (cron, Discord inbound), where exhaustion is a failed turn the caller handles (the cron fire is not counted successful; Discord sends no reply). The interactive pi session is user-driven, so a reasoning-only turn there just returns control. (`test/shell/reasoning-only-turn.test.ts`)
