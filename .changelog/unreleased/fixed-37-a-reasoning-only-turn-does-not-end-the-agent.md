- **A reasoning-only turn no longer ends the agent mid-task (#256).** A turn whose last assistant message carries no text and no tool call — only reasoning/thinking — is not a final answer, but pi treats a turn with no tool call as the agent being finished, so the run ended with the work unfinished. bob now re-prompts the SAME session with `Continue: take the next action, or give your final report.`, bounded to three consecutive reasoning-only endings, and then stops; the bound is a constant, so a model that answers with reasoning only cannot hold the run. A run still reasoning-only after the bound ends with the honest outcome `reasoning_only` and a bounded excerpt of the last reasoning, never a normal completion. Applies to every path that drives an agent run — the one-shot `bob run`, mail turns, `bob launch --prompt`, and every admitted runtime turn (cron, Discord inbound); the interactive pi session is user-driven, so a reasoning-only turn there just returns control.
