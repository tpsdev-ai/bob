- **The reachy transcript path rechecks the link epoch and the effective mute after the memory-attempt audit (bob#361).** A transcript accepted on one connection could write its private memory after the link reconnected, or the mute changed, while the attempt audit was awaited. It now records the connection epoch at acceptance and, after that audit, writes no memory and refuses — linked to the attempt event — when the epoch advanced or the link is effectively muted, the stale rule the action path already applies. A mute turned on and back off during the audit leaves the link unmuted but advances the epoch, so the epoch recheck refuses it; the mute recheck covers a mute still on at the recheck.
