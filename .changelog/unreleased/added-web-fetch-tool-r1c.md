- **The `web_fetch` tool: URL provenance, per-prompt fetch and text budgets, and web doctor checks (#246; slice R1c of #152).** `web_fetch {url, maxChars?}` fetches a URL and returns its readable text, final URL, HTTP status and content type. A URL is fetchable only if it appeared in the triggering message or on a page already fetched this prompt, resolved against its page and parsed with WHATWG URL with the fragment stripped; the serialized scheme, host, effective port, path and complete query are compared exactly, and the parsed URL is dispatched. An unrecorded URL is refused, suggesting search or asking for the link. Provenance and budgets belong to one admitted prompt: a fresh state is seeded at `before_agent_start`, cleared on a full `agent_settled` and on session close, and never on `agent_end`/`turn_start`/`turn_end`. Each call charges a fetch attempt before any I/O (so a failed call counts), ten per prompt by default, and returned text is charged against a shared allowance of 100,000 characters per prompt. A call outside an admitted prompt, or one whose running admission differs from the one the state was seeded for, is refused. `bob doctor` checks the web policy, refuses a known-private address and the NAT64 prefixes, and probes the fetch path without network I/O.
