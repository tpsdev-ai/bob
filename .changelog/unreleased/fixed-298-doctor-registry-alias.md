- **`bob doctor`'s subscription check resolves the provider name through the selected registry, and an operator alias for a subscription runtime is accepted (bob#298).** An operator row may point its runtime at a pi subscription provider (`openai-codex`, `github-copilot`, `xai`, `kimi-coding`) while still being refused a pi-owned `id` or alias, and doctor maps such an alias through the same registry a session uses, so the subscription-auth check runs. The session factory keys its keyed branch on the selected row's auth mode rather than the provider name, so a keyless row whose runtime is `openrouter` no longer reads `OPENROUTER_API_KEY`.
