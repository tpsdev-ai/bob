- **Past a per-run DELTA cap (50 MB) the streamed deltas stop, and nothing else does.** One line records that the DELTA cap was hit, naming the cap. Every non-delta event — tool calls and results, errors, lifecycle events, each `*_end` final and the closing `done` line — keeps being written, so a `message_end` still records its final message in full. What the cap trades away, plainly: a crash after the cap and before a `message_end` loses that message's post-cap tail. What it does not bound: those non-delta records themselves, which a run may write without limit — the cap is on the deltas, not on the log. (`test/shell/run-log.test.ts`)
