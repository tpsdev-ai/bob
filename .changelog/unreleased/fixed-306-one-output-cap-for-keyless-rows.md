- **A keyless row's budget bounds the output cap of every request to that row (bob#306).** The session factory lowers the model's `maxTokens` to the budget when the budget is smaller. Each request's output cap and bob's output backstop stay at or below the smaller of the budget and the model's `maxTokens`; pi may ask for less. The run log's `outputCap` is the session model's `maxTokens` when the run starts.
