- **The lockfile release-age check runs before install in CI and refuses `--registry` there.** The Dependency Audit job runs the check before the frozen install, so a refused lockfile stops the job before packages are fetched or installed. The checker refuses its loopback `--registry` test override when `CI` or `GITHUB_ACTIONS` is set. `minimumReleaseAgeExcludes` is honoured as written; widening it is protected by review (the main ruleset requires two approvals), not by the checker.
