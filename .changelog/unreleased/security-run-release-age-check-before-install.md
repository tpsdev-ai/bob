- **The lockfile release-age checker is the first `run:` step of each workflow job with a `run:` step, except release-publish.yml's verify-ancestry job.** An `actions/cache` step whose path has a component exactly `.bun` or `.npm`, and a `uses:` step with an input named `cache` or `install`, may not precede it. The checker refuses its loopback `--registry` test override when `CI` or `GITHUB_ACTIONS` is set. `minimumReleaseAgeExcludes` filters entries by exact package name before registry lookup.
