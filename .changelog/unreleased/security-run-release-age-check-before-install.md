- **The lockfile release-age checker is the first run step of every workflow job that runs commands, except the release workflow's ancestry guard job.** An `actions/cache` step whose path contains `.bun` or `.npm`, and a `uses:` step with an input named `cache` or `install`, may not precede it. The checker refuses its loopback `--registry` test override when `CI` or `GITHUB_ACTIONS` is set. `minimumReleaseAgeExcludes` is honoured as written; widening it is protected by review (the main ruleset, 16665054, verified via the API on 2026-11-05, requires two approving reviews and does not require a code owner's review), not by the checker.
