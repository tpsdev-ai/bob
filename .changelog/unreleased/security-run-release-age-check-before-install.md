- **The lockfile release-age checker runs before any project dependency install and any package-cache restore, and refuses `--registry` in CI.** In every job of every workflow it runs before any project dependency install and any package-cache restore, so a refused lockfile stops the job before packages are fetched or installed. A global tool install before it is allowed only where it is not a project install; none remains. The checker refuses its loopback `--registry` test override when `CI` or `GITHUB_ACTIONS` is set. `minimumReleaseAgeExcludes` is honoured as written; widening it is protected by review (the main ruleset, 16665054, verified via the API on 2026-11-05, requires two approving reviews and does not require a code owner's review), not by the checker.
