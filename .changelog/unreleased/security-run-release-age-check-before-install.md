- **The lockfile release-age check runs before install in every CI job that installs, and refuses `--registry` when `CI` or `GITHUB_ACTIONS` is set.** Each CI job that installs packages runs the check before its first install, so a refused lockfile stops the job before packages are fetched or installed. The checker refuses its loopback `--registry` test override when `CI` or `GITHUB_ACTIONS` is set. `minimumReleaseAgeExcludes` is honoured as written; widening it is protected by review (the main ruleset, 16665054, verified via the API on 2026-11-05, requires two approving reviews and does not require a code owner's review), not by the checker.
