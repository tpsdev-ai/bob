- **The PR-memory recall is cancelled with the run, and a run terminated before the session factory is invoked does not invoke it (#319).** The recall runs under the run's cancellation guard with the run's abort signal, so a run that a bound ends while recall is in flight cancels the recall request. The run's termination is checked again after recall returns and before the session factory is called. A cancelled recall is a recall failure: it is logged, and the round proceeds only while the run is live.
