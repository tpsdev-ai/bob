- **A compaction that starts after `agent_end` no longer re-prompts a finished run (bob#179).** The "what remains" note is sent after a compaction only while the agent is running. Once the agent has ended with a final message, a later compaction is post-completion: it neither clears that final message nor queues the note, so the run settles on the outcome it already reported instead of starting another turn. A compaction that interrupts a live run still sends the note. (`test/shell/compaction-after-agent-end.test.ts`)
