- **`bob onboard`, `bob run`, `bob align` and `bob install-service` accept the `--key=value` form of a flag.** A flag may now be written as `--model=claude-sonnet-4-6` or `--provider=exe-dev-gateway`, and the value is taken from that single argument; the space form (`--model claude-sonnet-4-6`) still works. Before this, `--model=foo` was read as a flag literally named `model=foo`, so `bob run --model=foo ember "task"` took `ember` (the agent's name) as the flag's value and lost it; the name now survives. An empty value on a value flag (`--model=`) means "not given" — the agent's own provider or model, or `bob onboard`'s default, applies — exactly as `--model` on its own does, which `bob onboard` used to write into `bob.yaml` as the literal id `true`.
