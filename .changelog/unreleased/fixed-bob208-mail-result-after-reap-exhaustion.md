- **A finished mail launcher can collect a result before the turn timeout when reap exhaustion leaves its output open (#208).** Once the launcher has exited and process-group reaping is exhausted, if result collection is still pending, Bob starts a result timer set to fire 250 ms later (subject to event-loop delay). If reaping is exhausted and that timer fires before the output closes, Bob ends result collection and then closes its output ends. If the timer fired before the turn timeout or shutdown, the launcher exited zero, and the turn is still active, the normal result parser uses the bytes already read. The bytes read at timer expiry decide the outcome: a complete result stands without rerunning the turn, while an incomplete result fails as `no-result`; bytes written later are not used. Under those conditions, result collection does not wait for the turn timeout. Parser use after reap exhaustion is logged with the group id, counted as `resultCollectedAfterReapExhausted`, and shown by `bob doctor` beside `reapExhausted`.
