- **A one-shot `bob run` always terminates: a wall clock, a per-call timeout with a retry, and a no-progress watchdog, each configurable (bob#135).**

  The wall clock ends the whole run; the per-call timeout ends a provider call that does not answer within its deadline, retried up to `call_retries` times; the watchdog ends a run whose run log stops growing. A bound that fires ends the run with a non-zero exit and a message naming the bound and how to raise it. The defaults are 30 minutes (wall clock), 5 minutes (per-call) and 10 minutes (watchdog), with one retry. bob.yaml's `run:` block (`wall_clock_seconds`, `call_timeout_seconds`, `call_retries`, `no_progress_seconds`) sets them per agent; `bob run`'s `--timeout`, `--call-timeout`, `--call-retries` and `--no-progress-timeout` flags override them for one run.
