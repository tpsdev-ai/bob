- **A one-shot `bob run` ends itself when a bound fires: a wall clock, a turn timeout and a no-progress watchdog (bob#135).**

  The wall clock and the watchdog start once the agent's configuration is resolved, before the Flair bootstrap and the session start. The wall clock ends the run when it expires; a prompt turn that misses the turn timeout ends the run, with no retry; the watchdog ends a run whose run log stops growing. A bound that fires ends the run with a non-zero exit and a message naming the bound and how to raise it, and the run sends no prompt after it. If the session has started, bob then signals its abort and waits at most 1 s for it, so a turn that never becomes idle cannot keep the process pending, and only then reads the workspace status; when the abort did not resolve, the report says the workspace may still be changing. The defaults are 30 minutes (wall clock), 5 minutes (turn) and 10 minutes (watchdog). bob.yaml's `run:` block (`wall_clock_seconds`, `turn_timeout_seconds`, `no_progress_seconds`) sets them per agent, and a second `run:` or a repeated key in it is refused; `bob run`'s `--timeout`, `--turn-timeout` and `--no-progress-timeout` flags override them for one run.
