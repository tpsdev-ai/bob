- **A one-shot `bob run` ends itself when a bound fires: a wall clock, a turn timeout with retries, and a no-progress watchdog (bob#135).**

  The wall clock ends the whole run; the turn timeout signals the stuck prompt turn to abort, retries it up to `turn_retries` times only once the session is idle, and otherwise ends the run; the watchdog ends a run whose run log stops growing. A bound that fires ends the run with a non-zero exit and a message naming the bound and how to raise it, and the abort is bounded, so a turn that never becomes idle cannot keep the process pending. The defaults are 30 minutes (wall clock), 5 minutes (turn) and 10 minutes (watchdog), with one retry. bob.yaml's `run:` block (`wall_clock_seconds`, `turn_timeout_seconds`, `turn_retries`, `no_progress_seconds`) sets them per agent; `bob run`'s `--timeout`, `--turn-timeout`, `--turn-retries` and `--no-progress-timeout` flags override them for one run.
