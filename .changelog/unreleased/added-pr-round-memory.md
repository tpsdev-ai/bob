- **A harness-owned per-PR round memory for builder PR rounds.** The HARNESS writes and recalls it; the model never issues a memory call and nothing is pasted into the brief. Identity is an exact key derived from the launcher-owned task binding — agent id, canonical repository and PR number via the new optional `TaskBinding.pr_ref` — never from the brief, model output, branch name or tool arguments. `bob run` and the programmatic `bob launch` path recall the PR's prior rounds before the session is built (a bounded, clearly labelled block: a signal, not an instruction) and write the round once at round end. The stored envelope is bounded (newest 3 rounds, each at most 4 KiB, whole envelope at most 16 KiB, omissions recorded) and holds structured evidence: the outcome from the harness exit code and termination reason, files from successful edit receipts, and checks where pending, missing and timed-out never become passes; no transcript, reasoning, environment or raw output is stored. A Flair outage never blocks the round (2 s request deadlines, a 404 is empty history, a failed read never overwrites history, and an unreachable Flair is reported and the round proceeds).
