- **A harness-owned per-PR round memory for builder PR rounds.** Identity comes from the launcher-owned `TaskBinding.pr_ref`. `bob run` recalls before session construction for sessions without web and attempts one write after the session runs or a run-bound abort during bootstrap or session construction; interactive `bob launch` without a prompt recalls only; launch with a prompt uses the `bob run` write path. Each round is stored as its own record of at most 16 KiB, with the round at most 4 KiB; recall shows up to 3 rounds, refuses oversized records, and bounding records omission categories. Outcomes come from the harness; files come from verified edit receipts; supplied check evidence is stored; the current one-shot runner collects none. A 404 within the response bound from the by-id read of the earlier single record means there is no earlier record; a 404 from the round listing makes recall unavailable. (`src/shell/pr-memory.ts`, `test/shell/pr-memory*.test.ts`)
