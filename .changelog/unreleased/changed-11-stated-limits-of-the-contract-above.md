- **Stated limits of the system-prompt task contract (under Added).** The task is sent in the first user message AND in every agent request's system prompt, so it costs tokens per request (the appended block is identical on every request of a run — pi rebuilds the prompt around it when the active tool set changes or on a reload, and the same text is appended each time — so a provider's prompt cache can cover it; it is not shared across runs). A failed best-effort "what remains" note can lose the text it would have quoted — the TASK is not lost, it is in the system prompt. And the completion judge checks for a real final MESSAGE, not that the work it describes was actually done.
